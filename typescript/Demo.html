Conditional Sentences

What is a Conditional Sentence?

A Conditional Sentence is a sentence that expresses a condition and its result (consequence).

Simple words me, Conditional Sentence batata hai ki "agar koi condition puri hogi, to kya result hoga."

Easy Definition

Jis sentence me kisi condition ke complete hone par uska result bataya jata hai, use Conditional Sentence kehte hain.

Basic Formula

If + Condition, Result

Yaha If condition ko introduce karta hai. Agar condition true hoti hai, tab result possible hota hai.

Parts of a Conditional Sentence

Condition Clause (If-Clause)

Ye batata hai ki kis condition ke complete hone par result milega.
Main Clause (Result Clause)

Ye batata hai ki condition complete hone ke baad kya result ya consequence hoga.

Example

If you study, you will pass.
Part Sentence
Condition If you study
Result You will pass.

More Examples

If it rains, we will stay at home.

Condition → If it rains
Result → We will stay at home.

If you work hard, you will succeed.

Condition → If you work hard
Result → You will succeed.

If I have money, I will buy a laptop.

Condition → If I have money
Result → I will buy a laptop.

Position of the Clauses

Conditional Sentence me If-Clause sentence ke starting me bhi aa sakta hai aur end me bhi aa sakta hai. Dono cases me meaning same rehta hai.

✔ If you study, you will pass.
✔ You will pass if you study.
Meaning dono sentences ka bilkul same hai.

Comma Rule (Very Important)

Agar sentence If-Clause se start hota hai, to comma ( , ) lagta hai.

✔ If you study, you will pass.

Agar Main Clause pehle aaye aur If-Clause baad me aaye, to comma nahi lagta.

✔ You will pass if you study.
❌ You will pass, if you study.

Banking Exam Point

Competitive Exams me Conditional Sentences se mainly in topics par questions aate hain:

  • Identify the Conditional Type
  • Error Detection
  • Fill in the Blanks
  • Verb Form
  • Sentence Improvement
  • Para Completion

Quick Revision

  • Conditional Sentence = Condition + Result
  • Basic Formula → If + Condition, Result
  • If-Clause = Condition
  • Main Clause = Result
  • Both clauses can change their position.
  • If-Clause first → Use comma (,)
  • Main Clause first → No comma
  • Competitive Exams me Verb Forms aur Conditional Types sabse important hote hain.

Types of Conditional Sentences

Conditional Sentences ko mainly 5 Types me divide kiya jata hai. Har type ka apna alag structure, meaning aur usage hota hai.

Banking, SSC, CDS, AFCAT, CAT aur State Exams me sabse jyada questions Conditional Types, Verb Forms aur Error Detection se puchhe jate hain.

Easy Formula:
  • Zero → Fact
  • First → Future Possibility
  • Second → Present/Future Imagination
  • Third → Past Regret
  • Mixed → Combination of Past & Present
Type Time Structure Use
Zero Always True Present → Present Facts
First Future Present → Will + V1 Real Possibility
Second Present/Future Past → Would + V1 Imaginary Situation
Third Past Had + V3 → Would have + V3 Past Regret
Mixed Past + Present Mixed Structure Mixed Time

1️⃣ Zero Conditional

Zero Conditional ka use un situations ke liye hota hai jo 100% true, always true ya generally true hoti hain.

Iska use kisi bhi aise fact ke liye kiya jata hai jo har baar same result deta hai. Agar condition complete hoti hai to result bhi hamesha same hota hai. Isliye Zero Conditional me future, imagination ya possibility ki baat nahi hoti.

Easy Definition

Jab condition aur result dono hamesha true ho, tab Zero Conditional use hota hai.

If this happens, this always happens.

Structure

If + Subject + Present Simple, Subject + Present Simple
If + V1 (Present Simple) ➜ Present Simple

How Zero Conditional Works?

Zero Conditional me condition complete hote hi result naturally ya automatically hota hai. Isme future prediction nahi hoti.

Example:

If you heat water, it boils.
Condition: You heat water.

Result: Water boils.

Ye har baar hota hai. Isliye ye Zero Conditional hai.

Uses of Zero Conditional

1. Universal Truths

Aise facts jo duniya me hamesha true hote hain.

  • If the sun sets, it becomes dark.
  • If the Earth revolves around the Sun, seasons change.
  • If you drop an object, it falls to the ground.

2. Scientific Facts

  • If you heat water to 100°C, it boils.
  • If ice melts, it becomes water.
  • If water freezes, it becomes ice.
  • If plants do not get sunlight, they die.

3. General Truths

  • If you exercise regularly, you stay healthy.
  • If you don't sleep well, you feel tired.
  • If children eat too much chocolate, they get tooth decay.

4. Instructions / Rules

  • If you press this button, the machine starts.
  • If you touch this wire, you get an electric shock.
  • If you enter the wrong password, the system locks.

More Examples

If you mix blue and yellow, you get green.
If you don't water plants, they die.
If babies are hungry, they cry.
If people don't eat, they become weak.
If iron gets wet, it rusts.
If you study regularly, you learn faster.

Important Rules

Rule 1: Present Simple dono clauses me use hota hai.
✔ If you heat ice, it melts.
Rule 2: If-Clause me "Will" use nahi hota.
❌ If you will heat water, it boils.
✔ If you heat water, it boils.
Rule 3: Result bhi Present Simple me hota hai.

Common Exam Errors

❌ If you heat water, it will boil.

✔ If you heat water, it boils.
❌ If water reaches 100°C, it will boil.

✔ If water reaches 100°C, it boils.
❌ If you don't eat, you will become weak.

✔ If you don't eat, you become weak.

Banking Exam Tips

  • Zero Conditional = Facts + General Truths
  • Scientific Facts me mostly Zero Conditional use hota hai.
  • Both clauses = Present Simple
  • Future tense ("Will") generally use nahi hota.
  • Error Detection me "If + Will" sabse common trap hai.

Zero vs First Conditional

Zero Conditional First Conditional
Always True Future Possibility
Present → Present Present → Will + V1
If you heat water, it boils. If you heat water, it will boil.

B. will become

Answer: A. becomes

Q2. If you don't sleep well, you ______ tired.

A. become
B. will become
C. became
D. would become

Answer: A. become

Q3. If plants don't get sunlight, they ______.

A. die
B. will die
C. died
D. would die

Answer: A. die

Quick Revision

  • Zero Conditional = Universal Truth + Scientific Fact + General Truth
  • Formula → If + Present Simple → Present Simple
  • Both clauses Present Simple me hote hain.
  • "Will" generally use nahi hota.
  • Competitive Exams me "If + Will" sabse common error hoti hai.

2️⃣ First Conditional

First Conditional ka use un situations ke liye hota hai jo future me possible hain. Matlab condition abhi sure nahi hai, lekin agar condition complete ho gayi, to result bhi future me hone ki possibility hai.

Ye Conditional Real Future Possibility ko express karta hai. Isme condition imaginary ya impossible nahi hoti. Bas future me hone ki possibility hoti hai.

Easy Definition

Agar future me koi condition complete hogi, to uska result bhi future me milega.

If this happens in future, this will happen.

Structure

If + Subject + Present Simple, Subject + Will + V1
If + Present Simple ➜ Will + Base Verb (V1)

How First Conditional Works?

Isme condition future me complete ho sakti hai. Agar condition complete hoti hai to result bhi future me hoga.

Example:

If you study hard, you will pass.
Condition: You study hard.

Result: You will pass.

Passing guaranteed nahi hai, lekin possibility hai.

Uses of First Conditional

1. Real Future Possibility

Jab future me kisi event ke hone ki real possibility ho.

  • If it rains, we will stay at home.
  • If you work hard, you will succeed.
  • If she studies well, she will pass.

2. Warnings

  • If you drive fast, you will have an accident.
  • If you don't wear a helmet, you will get injured.
  • If you don't pay the bill, your connection will be disconnected.

3. Promises

  • If you help me, I will help you.
  • If you come tomorrow, I will give you the notes.
  • If you trust me, I will never disappoint you.

4. Offers & Requests

  • If you need help, I will assist you.
  • If you call me, I will answer immediately.
  • If you visit Delhi, I will show you around.

More Examples

If you exercise daily, you will stay healthy.
If they invite us, we will attend the party.
If she arrives early, she will meet the manager.
If I get the job, I will buy a new bike.
If you save money, you will become financially secure.
If he apologizes, I will forgive him.

Important Rules

Rule 1: If-Clause me hamesha Present Simple use hota hai.
✔ If you study, you will pass.
Rule 2: Main Clause me Will + V1 use hota hai.
✔ I will help you.
Rule 3: If-Clause me Will use nahi hota.
❌ If you will study, you will pass.
✔ If you study, you will pass.
Rule 4: If-Clause Present me hota hai, lekin meaning Future ka hota hai.

Common Banking Exam Errors

❌ If you will come, I will help you.

✔ If you come, I will help you.
❌ If it will rain, we will stay home.

✔ If it rains, we will stay home.
❌ If she studies, she passes.

✔ If she studies, she will pass.
❌ If I get time, I go there.

✔ If I get time, I will go there.

Zero Conditional vs First Conditional

Zero Conditional First Conditional
Facts Future Possibility
Always True May Happen
Present → Present Present → Will + V1
If water boils, it evaporates. If it rains tomorrow, we will stay home.

Quick Revision

  • First Conditional = Real Future Possibility
  • Formula → If + Present Simple → Will + V1
  • If-Clause me "Will" use nahi hota.
  • Main Clause me "Will + V1" use hota hai.
  • Use for future plans, promises, warnings, offers and real possibilities.
  • Competitive Exams me sabse common error → If + Will.

3️⃣ Second Conditional

Second Conditional ka use aisi situations ke liye hota hai jo present ya future me unreal (asambhav), imaginary (kalpanik), ya very unlikely (bahut kam possibility wali) hoti hain.

Matlab speaker kisi aisi situation ki baat kar raha hota hai jo reality me nahi hai, lekin agar hoti to uska kya result hota.

Easy Definition

Jab hum present ya future ki kisi imaginary ya impossible condition ki baat karte hain, tab Second Conditional use hota hai.

If this were true, this would happen.

Structure

If + Subject + Past Simple, Subject + Would + V1
If + Past Simple ➜ Would + Base Verb (V1)

How Second Conditional Works?

Isme condition reality me true nahi hoti. Speaker sirf imagine karta hai ki agar aisa hota to kya hota.

Example:

If I were rich, I would buy a private jet.
Reality: I am not rich.

Ye sirf imagination hai.

Uses of Second Conditional

1. Imaginary Present Situation

Jab present me koi cheez reality me nahi hai.

  • If I were rich, I would buy a Ferrari.
  • If I had more time, I would learn Japanese.
  • If I knew French, I would work in Paris.

2. Unreal Future Situation

  • If I won the lottery, I would travel the world.
  • If aliens visited Earth, people would panic.
  • If robots ruled the world, life would be different.

3. Giving Advice

"If I were you..." English ka bahut common expression hai.

  • If I were you, I would apologize.
  • If I were you, I would accept the offer.
  • If I were you, I would prepare for the exam.

4. Dreams & Wishes

  • If I had wings, I would fly.
  • If I were a bird, I would fly across the world.
  • If I were invisible, I would help people secretly.

More Examples

If I were a millionaire, I would build a school.
If she knew the truth, she would be shocked.
If we had a bigger house, we would invite everyone.
If I were the Prime Minister, I would improve education.
If he had enough money, he would buy a BMW.
If they lived nearby, they would visit us every weekend.

Very Important Rule (Were Rule)

Formal English aur Competitive Exams me Second Conditional me Were use kiya jata hai, chahe Subject singular hi kyu na ho.

✔ If I were rich...
✔ If he were here...
✔ If she were my sister...
❌ If I was rich...
❌ If he was here...
Exam Tip: Banking aur SSC Exams me "If I were..." ko correct mana jata hai.

Important Rules

Rule 1: If-Clause me Past Simple use hota hai.
Rule 2: Main Clause me Would + V1 use hota hai.
Rule 3: If-Clause me Would use nahi hota.
❌ If I would study, I would pass.
✔ If I studied, I would pass.
Rule 4: "Were" ka use "Was" ki jagah kiya jata hai.

Common Banking Exam Errors

❌ If I was rich, I would buy a car.

✔ If I were rich, I would buy a car.
❌ If I would study, I would pass.

✔ If I studied, I would pass.
❌ If she knew, she will tell us.

✔ If she knew, she would tell us.
❌ If he had money, he will buy a house.

✔ If he had money, he would buy a house.

First Conditional vs Second Conditional

First Conditional Second Conditional
Real Future Possibility Unreal / Imaginary Situation
If + Present → Will + V1 If + Past → Would + V1
If I get money, I will buy a car. If I had money, I would buy a car.

Quick Revision

  • Second Conditional = Unreal / Imaginary Present or Future
  • Formula → If + Past Simple → Would + V1
  • Use Were, not Was (Formal English)
  • If-Clause me Would use nahi hota.
  • Advice dene ke liye "If I were you..." bahut common expression hai.
  • Banking Exams ka favourite trap: If I was... ❌ → If I were... ✅

4️⃣ Third Conditional

Third Conditional ka use un situations ke liye hota hai jo past me ho sakti thi lekin hui nahi. Ye unreal past situations, regrets (pachtawa), criticism aur missed opportunities ko express karta hai.

Is Conditional me hum past ko change nahi kar sakte. Hum sirf imagine karte hain ki agar past me kuch aur hua hota, to result bhi alag hota.

Easy Definition

Jab hum kisi aise past event ki baat karte hain jo reality me nahi hua, aur uske imaginary result ko batate hain, tab Third Conditional use hota hai.

If this had happened, this would have happened.

Structure

If + Subject + Had + V3, Subject + Would Have + V3
If + Had + Past Participle (V3) ➜ Would Have + V3

How Third Conditional Works?

Third Conditional me condition aur result dono hi past se related hote hain. Dono imaginary hote hain kyunki actual event already ho chuka hota hai.

Example:

If I had studied harder, I would have passed the exam.
Reality: I did not study hard.

Result: I did not pass the exam.

Ye sirf past ki imagination hai.

Uses of Third Conditional

1. Past Regret

Kisi past mistake ka regret express karna.

  • If I had studied harder, I would have passed.
  • If I had listened to my parents, I would have succeeded.
  • If she had left earlier, she would have caught the train.

2. Missed Opportunity

  • If he had accepted the job, he would have earned more.
  • If we had invested earlier, we would have made a profit.
  • If they had booked tickets earlier, they would have travelled.

3. Criticism

  • If you had driven carefully, the accident would not have happened.
  • If he had followed the rules, he would not have been punished.
  • If she had prepared well, she would not have failed.

4. Imaginary Past Situation

  • If I had been born in Japan, I would have spoken Japanese.
  • If I had known the truth, I would have helped you.
  • If they had invited me, I would have attended the party.

More Examples

If I had woken up early, I would have caught the bus.
If she had invited me, I would have attended the wedding.
If they had saved money, they would have bought a house.
If the driver had been careful, the accident would not have happened.
If we had reached earlier, we would have met the manager.
If he had prepared well, he would have cleared the interview.

Important Rules

Rule 1: If-Clause me hamesha Had + V3 use hota hai.
Rule 2: Main Clause me Would Have + V3 use hota hai.
Rule 3: If-Clause me "Would Have" use nahi hota.
❌ If I would have studied, I would have passed.
✔ If I had studied, I would have passed.
Rule 4: Dono clauses past imaginary situations ko show karte hain.

Common Banking Exam Errors

❌ If I would have studied, I would have passed.

✔ If I had studied, I would have passed.
❌ If he had worked hard, he would pass.

✔ If he had worked hard, he would have passed.
❌ If they had reached early, they would catch the train.

✔ If they had reached early, they would have caught the train.
❌ If she had came, I would have helped her.

✔ If she had come, I would have helped her.

Second Conditional vs Third Conditional

Second Conditional Third Conditional
Present / Future Past
Unreal Present/Future Unreal Past
If + Past → Would + V1 If + Had + V3 → Would Have + V3
If I were rich, I would buy a car. If I had been rich, I would have bought a car.

Quick Revision

  • Third Conditional = Unreal Past Situation
  • Formula → If + Had + V3 → Would Have + V3
  • Use for Regret, Missed Opportunity, Criticism and Imaginary Past.
  • If-Clause me Would Have kabhi use nahi hota.
  • Main Clause me Would Have + V3 use hota hai.
  • Competitive Exams ka favourite trap: If I would have... ❌ → If I had... ✅
  • Had ke baad hamesha V3 (Past Participle) aata hai.

5️⃣ Mixed Conditional

Mixed Conditional ka use tab hota hai jab Condition aur Result different time periods se belong karte hain.

Normally baaki Conditional Sentences me Condition aur Result same time ke hote hain (Present-Present, Past-Past, Future-Future). Lekin Mixed Conditional me Past aur Present/Future ko mix kiya jata hai.

Easy Definition

Jab Condition ek time ki ho aur Result kisi doosre time ka ho, tab Mixed Conditional use hota hai.

Different Time = Mixed Conditional

Why is it Called "Mixed"?

Iska naam "Mixed" isliye hai kyunki sentence me do alag-alag time periods use hote hain.

Example:

If I had studied harder, I would be successful now.
Condition → Past
I didn't study.

Result → Present
I am not successful now.

Types of Mixed Conditional

Type 1: Past ➜ Present

Past ki kisi action ka effect Present me dikh raha ho.

Structure

If + Subject + Had + V3, Subject + Would + V1
Examples:
  • If I had studied harder, I would have a better job now.
  • If she had accepted the offer, she would live in London now.
  • If they had invested wisely, they would be rich today.
  • If he had taken medicine, he would be healthy now.
Meaning: Past mistake ka effect aaj tak chal raha hai.

Type 2: Present ➜ Past

Present ki unreal situation ki wajah se Past me result different hota.

Structure

If + Subject + Past Simple, Subject + Would Have + V3
Examples:
  • If I were rich, I would have bought that house last year.
  • If she were more confident, she would have attended the interview.
  • If he were taller, he would have joined the army.
  • If they lived nearby, they would have visited us yesterday.
Meaning: Present situation alag hoti to Past result bhi alag hota.

More Examples

If I had completed my degree, I would have a good job now.
If she had learned English, she would work abroad now.
If they had saved money, they would own a house today.
If I were a doctor, I would have treated him yesterday.
If he were careful, he wouldn't have lost his wallet.
If we had booked tickets earlier, we would be in Goa now.

Important Rules

Rule 1: Mixed Conditional me Time Change hota hai.
Rule 2: Condition aur Result same time ke nahi hote.
Rule 3: Past ➜ Present
If + Had + V3 ➜ Would + V1
Rule 4: Present ➜ Past
If + Past ➜ Would Have + V3

Common Banking Exam Errors

❌ If I had studied, I would have a good job yesterday.

✔ If I had studied, I would have a good job now.
❌ If I were rich, I would buy that car yesterday.

✔ If I were rich, I would have bought that car yesterday.
❌ If she had accepted the job, she would have lived in Delhi now.

✔ If she had accepted the job, she would live in Delhi now.
❌ If I would have studied, I would be successful now.

✔ If I had studied, I would be successful now.

Third Conditional vs Mixed Conditional

Third Conditional Mixed Conditional
Past ➜ Past Past ➜ Present
If I had studied, I would have passed. If I had studied, I would be successful now.
Both clauses are about the past. Condition is in the past, result is in the present.

Quick Revision

  • Mixed Conditional = Different Time Periods
  • Past → Present = If + Had + V3 → Would + V1
  • Present → Past = If + Past → Would Have + V3
  • Used when Condition aur Result alag-alag time ke hote hain.
  • Past mistake ka present effect ya Present unreal situation ka past effect dikhane ke liye use hota hai.
  • Competitive Exams me Mixed Conditional ko Third Conditional ke saath confuse karna sabse common mistake hoti hai.

Banking Exam Favourite Traps

  • ❌ If + Will
  • ❌ If I was rich...
  • ❌ Had + V2
  • ❌ Would after If-Clause
  • ❌ Wrong use of Would Have
